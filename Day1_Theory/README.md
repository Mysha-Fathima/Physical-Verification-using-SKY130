# Day 1 – SKY130 PDK & Open-Source EDA Fundamentals

## Overview

The first day of the VSD Physical Verification workshop focused on understanding the SKY130 open-source Process Design Kit (PDK) and the open-source EDA ecosystem used for VLSI design and physical verification.

## Topics Covered

- Introduction to the SKY130 PDK
- Open-source EDA tools and their applications
- SKY130 technology and physical layers
- Basic layout and device concepts
- Digital standard-cell and library concepts
- Role of PDKs and libraries in physical design

## Tools & Technologies

- SKY130 Open-Source PDK
- Open-source EDA tools
- Linux-based design environment

## Key Learning

The session provided an introduction to the technology-specific information provided by a PDK and its importance in semiconductor design. I also learned about the relationship between technology layers, devices, libraries and EDA tools used in the physical design flow.
