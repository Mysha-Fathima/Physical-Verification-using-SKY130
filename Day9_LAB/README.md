# Day 9 – LVS Check Lab
 
## Overview
The ninth day of the VSD Physical Verification workshop was a hands-on
lab session applying LVS concepts from Day 8 to real layout-vs-schematic
comparisons using Netgen, across increasingly complex scenarios.
 
## Tools & Technologies
- SKY130 Open-Source PDK
- Magic
- Netgen
- Linux terminal environment
## Key Learning
Gained hands-on experience running Netgen LVS checks across simple
circuits, subcircuits, macros, and parasitic-aware comparisons, and
reading match/mismatch reports for each.
