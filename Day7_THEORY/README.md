# Day 7 – PNR Fundamentals & Hands-on Techniques
 
## Overview
The seventh day of the VSD Physical Verification workshop covered Place
and Route (PNR) fundamentals using OpenLane, combining the RTL-to-GDS
flow theory with interactive, hands-on OpenLane practice.
 
## Tools & Technologies
- SKY130 Open-Source PDK
- OpenLane
- RTL2GDS flow
- Linux-based design environment
## Key Learning
This session built an understanding of how a digital design moves from
RTL to a finished GDSII layout through the OpenLane flow, and gave
hands-on practice running and interacting with each stage of that flow.
