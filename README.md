# Physical Verification using SKY130

10-day VSD Physical Verification workshop using the SKY130 open-source PDK
and open-source EDA tools (Magic, Netgen, Xschem, NGSPICE).

## Tools & Technologies
- SKY130 Open-Source PDK
- Magic VLSI
- Netgen
- Xschem
- NGSPICE
- Linux-based design environment
