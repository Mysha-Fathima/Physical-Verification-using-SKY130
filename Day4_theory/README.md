# Day 4 – GDS Read & Physical Verification Lab

## Overview

The fourth day of the VSD Physical Verification workshop focused on practical GDS handling and preparation for physical verification. The lab covered GDS reading, ports, abstract views, basic extraction and setup activities for DRC, LVS and XOR verification.

## Tools & Technologies

- SKY130 Open-Source PDK
- GDS layout data
- Magic
- Netgen
- Physical Verification tools
- DRC
- LVS
- XOR

## Key Learning

The session provided hands-on understanding of how GDS-based physical design data is examined and prepared for different physical verification checks. I gained practical exposure to layout data, ports, abstract views, extraction and verification setup.
