# Day 2 – Hands-on SKY130 Physical Design Lab

## Overview

The second day of the VSD Physical Verification workshop focused on hands-on interaction with the SKY130 design environment and open-source EDA tools. The practical session provided experience with the layout environment, terminal-based workflow, design files and simulation results.

## Topics Covered

- Introduction to the hands-on SKY130 design environment
- Working with the Magic layout tool
- Terminal-based EDA workflow
- Understanding layout representations and technology layers
- Working with inverter-related design files
- Circuit simulation and waveform observation

## Tools & Technologies

- SKY130 Open-Source PDK
- Magic
- Netgen
- Xschem
- NGSPICE
- Linux terminal environment

## Practical Work

The lab involved launching the required tools, working with SKY130-related files and commands, examining the physical layout and observing simulation results.

## Key Learning

The practical session helped me understand how circuit-level information, layout data and verification tools are connected in a physical design workflow. I gained hands-on familiarity with the open-source EDA environment and the basic process of moving between design, layout and simulation stages.
