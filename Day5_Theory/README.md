# Day 5 – Design Rule Checking (DRC) Fundamentals

## Overview

The fifth day of the VSD Physical Verification workshop focused on Design Rule Checking (DRC) and the technology-specific rules used to validate an IC layout. The session covered different categories of SKY130 physical design rules and their role in ensuring layout correctness.

## Tools & Technologies

- SKY130 Open-Source PDK
- Design Rule Checking (DRC)
- Physical Verification
- Layout Design Rules
- IC Physical Design

## Key Learning

The session helped me understand the purpose of DRC and how different categories of technology-specific rules are applied to physical layouts. I learned about rules associated with metals, local interconnects, front-end layers, wells, devices, density and other recommended design constraints.
